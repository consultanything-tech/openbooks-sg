# Changelog

All notable changes to OpenBooks SG will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-24

### Added
- Core accounting: invoices, bills, quotes, credit notes
- Chart of accounts with journal entries and ledger reports
- Banking with multi-account management, transfers, and reconciliation
- OFX / QBO / CSV bank statement import
- Inventory management with stock tracking and low-stock alerts
- Time tracking with convert-to-invoice workflow
- Expense claims with multi-step approval
- Budget creation and tracking
- Recurring invoice/bill templates with scheduling
- Customer self-service portal
- Reports: P&L, Balance Sheet, AR/AP Aging, Income & Expense, GST F5
- Custom report builder with save and CSV export
- AI assistant with natural-language chat (NVIDIA NIM)
- Receipt OCR for automated expense entry
- PayNow QR / SGQR payment integration
- REST API v1 with 20 endpoints and Bearer token auth
- Role-based access control (ADMIN, ACCOUNTANT, VIEWER)
- Two-factor authentication (TOTP)
- Web installer for first-time setup
- Database backup and restore from dashboard
- Activity log with audit trail
- PWA support with offline page
- English and Malay localization
- Docker deployment (PHP-FPM + Nginx + MySQL)
- Webhooks for external integrations
- Automated payment reminder emails
- Keyboard shortcuts for power users
